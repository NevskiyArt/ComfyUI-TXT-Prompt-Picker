# Публикация TXT Prompt Picker в ComfyUI Registry

Памятка для NevskiyArt. Актуальная официальная документация: https://docs.comfy.org/registry/publishing

## 1. Проверить GitHub

Убедитесь, что в корне репозитория находятся `__init__.py`, `nodes.py`, `routes.py`, `pyproject.toml`, `LICENSE`, `README.md`, `README_RU.md`, а вложенные файлы лежат в `web/picker.js` и `.github/workflows/publish.yml`.

Если файлы размещены в другом месте, пользователь не получит кнопку выбора TXT, а GitHub Actions не обнаружит действие публикации.

## 2. Создать издателя

1. Откройте https://registry.comfy.org/ и авторизуйтесь.
2. Создайте Publisher. Желаемый ID: `nevskiyart`.
3. Если этот ID занят или отличается от зарегистрированного, исправьте `PublisherId` в `pyproject.toml` **до публикации**. ID является постоянным.
4. Создайте Publisher API key для публикации; сохраните его конфиденциально.

## 3. Настроить GitHub Actions

1. Репозиторий → **Settings → Secrets and variables → Actions**.
2. **New repository secret** → Name: `REGISTRY_ACCESS_TOKEN` → Secret: API-ключ издателя Comfy Registry.
3. Ключ **никогда** не помещайте в исходники, README, Issues или скриншоты.

## 4. Запуск публикации

1. Перейдите в **Actions** репозитория.
2. Выберите **Publish to Comfy Registry**.
3. Нажмите **Run workflow** → `main`.
4. Дождитесь успешного завершения и откройте карточку расширения в Registry.

Факт запуска задания не гарантирует мгновенное появление в поиске Manager: могут понадобиться индексация или проверка пакета.

## 5. Выпуск новой версии

Измените номер версии `version` в `pyproject.toml` (например, `1.1.0` → `1.1.1`) и повторно запустите публикацию. Один и тот же опубликованный номер версии повторно использовать нельзя.

## Загрузка проекта на GitHub без потери структуры папок

Рекомендовано **GitHub Desktop**. Распакуйте комплект, затем либо клонируйте уже существующий репозиторий и скопируйте файлы внутрь, либо создайте локальный репозиторий из папки проекта и опубликуйте его через Desktop. Загрузка всех файлов через браузер может разложить файлы из скрытой `.github` и папки `web` в корень.
