# TXT Prompt Picker для ComfyUI

**Автор: NevskiyArt** · Версия **1.3.0** · [English README](README.md)

Расширение добавляет в ComfyUI узел, который позволяет **выбрать TXT через обычное окно выбора файла** и **запустить все промпты по очереди одной кнопкой**.

## Возможности

- Выбор TXT из любой папки на компьютере, без ручного указания пути.
- Автоматическая постановка всех промптов в очередь ComfyUI.
- Кнопка **⏹ Stop Entire Series** прерывает текущую генерацию и очищает оставшуюся общую очередь ComfyUI. **Важно:** ожидающие задания других workflow тоже удаляются.
- Разделение промптов по строкам, пустым строкам или разделителю `---`.
- Установка начальной позиции через `seed` (`0` — первый промпт).
- Кодировки UTF-8, UTF-8 с BOM, Windows-1251, UTF-16 с BOM.
- Размер TXT до **10 МиБ**.
- Выход типа `STRING` — можно подключать к FLUX, Qwen-Image, Z-Image и другим моделям, которые принимают текстовый промпт.

## Установка

### Через ComfyUI Manager

Когда расширение будет **опубликовано и доступно** в [Comfy Registry](https://registry.comfy.org/), найдите **TXT Prompt Picker by NevskiyArt** через менеджер ComfyUI и установите его. Публикация исходников на GitHub сама по себе не добавляет узел в каталог.

### Вручную

1. На странице репозитория GitHub нажмите **Code → Download ZIP**.
2. Распакуйте скачанный архив в папку `custom_nodes` именно той установки ComfyUI, которой пользуетесь.
3. Проверьте, что получилась структура:

   ```text
   ComfyUI/
   └── custom_nodes/
       └── ComfyUI-TXT-Prompt-Picker/
           ├── __init__.py
           ├── nodes.py
           ├── routes.py
           └── web/
               └── picker.js
   ```

   Папка расширения не должна оказаться внутри ещё одной одноимённой папки.

4. Перезапустите ComfyUI. Если кнопки не появились, обновите страницу `Ctrl+F5`.
5. В поиске узлов наберите `TXT`, добавьте **«📄 TXT Prompt Picker»** (категория `TXT Prompts`).

## Использование

1. Подключите выход `prompt` к текстовому входу генерации.
2. Нажмите **«📂 Choose TXT File...»** и выберите файл в обычном Проводнике Windows.
3. Выберите способ разделения:
   - **Одна строка** — каждый непустой ряд текста считается отдельным промптом;
   - **Пустая строка** — один промпт может занимать несколько строк, соседние промпты отделяются пустой строкой;
   - **Разделитель ---** — между промптами используется отдельная строка `---`.
4. Укажите `seed = 0`, чтобы начать с первого промпта.
5. Нажмите **«▶ Generate All Prompts»**. Узел добавит в очередь столько заданий, сколько промптов найдено в файле.

### Пример для режима «Одна строка»

```text
beautiful fantasy witch, enchanted forest
gothic vampire queen, moonlit castle
fantasy knight, dramatic lighting
```

### Пример многострочных промптов с разделителем

```text
A fantasy witch portrait.
Cinematic lighting, detailed clothes.
---
A gothic castle.
Dark, rainy night, full moon.
```

## Важные нюансы

- При выборе TXT файл **загружается на сервер ComfyUI** и сохраняется под внутренним именем в `input/txt_prompt_picker/`. Изменили исходный TXT — выберите его повторно.
- Экспортированный workflow JSON **не содержит текст исходного TXT**, поэтому другой пользователь должен выбрать свой файл.
- Кнопка запуска формирует очередь. Число изображений на один промпт зависит от остального workflow.
- Версия 1.3 проверена на практике в ComfyUI Desktop; работа во всех конфигурациях ComfyUI отдельно не гарантируется.

## Остановка всей серии

В самом узле нажмите **⏹ Stop Entire Series**. Расширение прекращает добавлять новые промпты, отправляет команду прерывания текущей генерации и очищает оставшуюся очередь ComfyUI.

**Важно:** ComfyUI использует общую очередь. Кнопка удалит и ожидающие задания других workflow, если они были запущены одновременно. Сохранённые изображения не удаляются.

В версии 1.3 подписи интерфейса на английском; старые workflow с русскими значениями режимов разделения промптов поддерживаются.
