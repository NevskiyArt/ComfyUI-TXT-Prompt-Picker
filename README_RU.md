# TXT Prompt Picker для ComfyUI — NevskiyArt

Узел для **автоматической генерации изображений по списку промптов из TXT**.

## Что умеет

- Кнопка **«📂 Выбрать TXT...»** открывает окно выбора файла, без ручного ввода путей.
- Кнопка **«▶ Генерировать весь TXT»** добавляет все промпты в очередь ComfyUI.
- Три способа разделения: каждый промпт на отдельной строке, пустая строка между промптами, разделитель `---`.
- Поддержка UTF-8, Windows-1251 и UTF-16 с BOM; файл до 10 МиБ.
- Работает с моделями, принимающими строковый промпт (FLUX, Qwen, Z-Image и другие).

## Установка

1. На GitHub нажмите **Code → Download ZIP**.
2. Распакуйте файлы расширения в отдельную папку `ComfyUI/custom_nodes/ComfyUI-TXT-Prompt-Picker/`.
3. Убедитесь, что файлы `__init__.py`, `nodes.py`, `routes.py` и папка `web` находятся **прямо в папке расширения**, без двойной вложенности.
4. Перезапустите ComfyUI, при необходимости обновите страницу `Ctrl + F5`.
5. Найдите узел **«📄 TXT → Промпты по очереди»** в поиске узлов.

## Использование

1. Подключите выход `prompt` узла к текстовому входу генерации.
2. Нажмите **«📂 Выбрать TXT...»** и выберите файл на компьютере.
3. Укажите способ разделения промптов.
4. Для первого промпта установите `seed = 0`.
5. Нажмите **«▶ Генерировать весь TXT»**.
6. ComfyUI добавит столько заданий, сколько промптов найдено в файле, и выполнит их последовательно.

Пример TXT-файла с тремя промптами:

```text
beautiful fantasy witch, dark forest
gothic vampire queen, ancient castle
epic warrior, magic sword
```

**Важно:** TXT загружается внутрь ComfyUI в папку `input/txt_prompt_picker/` под внутренним именем; изменение исходного TXT на компьютере не обновляет список автоматически — выберите файл повторно. Экспортированный workflow JSON не содержит сам TXT.

## Для публикации в ComfyUI Registry

В `pyproject.toml` нужно проверить две строки: `PublisherId` — ID вашего профиля издателя в [Comfy Registry](https://registry.comfy.org/), `Repository` — адрес этого репозитория на GitHub. Для публикации через GitHub Actions создайте секрет `REGISTRY_ACCESS_TOKEN` с **API-ключом издателя Comfy Registry** и запустите действие **Publish to Comfy Registry** вручную.
